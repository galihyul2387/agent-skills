## ✅ Checklist Sebelum Review
<!-- Pastikan semua item dicek sebelum meminta review -->
- [ ] Kode telah lolos `npm run lint` tanpa error
- [ ] Unit test telah ditulis dan semua test lolos (`npm run test`)
- [ ] Tidak ada kredensial atau secret yang ter-hardcode
- [ ] Perubahan telah diuji secara manual di lingkungan lokal
- [ ] Dokumentasi API / README telah diperbarui (jika relevan)
- [ ] Commit message mengikuti format Conventional Commits

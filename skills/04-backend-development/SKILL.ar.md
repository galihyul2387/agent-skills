# دليل المرحلة: تطوير الواجهة الخلفية والخدمات المصغرة وضمان الجودة

تركز هذه المرحلة على منطق الأعمال في جانب الخادم، وتصميم بنية الخدمات المصغرة، وعزل قواعد البيانات لكل خدمة، وتغطية الاختبارات، ومعايير SonarQube A+، وترويسات أمان HTTP، وتوحيد رسائل الأخطاء وفق RFC 7807.

## 1. البنية المعمارية للخدمات المصغرة

*   **تفكيك الخدمات:** تقسيم الخدمات وفق النطاقات (المصادقة، المستخدمين، المعاملات).
*   **عزل قواعد البيانات (Database per Service):** قاعدة بيانات مستقلة لكل خدمة لمنع الترابط الوثيق.
*   **التواصل المتزامن وغير المتزامن:** استخدام gRPC/REST للتزامن، و Kafka/RabbitMQ للرسائل غير المتزامنة.

---

## 2. معايير الجودة SonarQube A+ والاختبارات

*   **تغطية الاختبارات:** تحقيق نسبة **80% إلى 90%** للمنطق التجاري.
*   **انعدام الثغرات:** تحقيق تصنيف SonarQube A+ (0 ثغرات، 0 أخطاء حرجة، التكرار < 3%).

---

## 3. ترويسات الأمان HTTP ومكافحة الأتمتة

*   `Strict-Transport-Security: max-age=31536000; includeSubDomains` (HSTS)
*   `Content-Security-Policy: default-src 'self'`
*   `X-Frame-Options: DENY`
*   `X-Content-Type-Options: nosniff`
*   **تحديد معدل الطلبات (Rate Limiting):** حماية المنافذ من الهجمات العنيفة.

---

## 4. معيار أخطاء RFC 7807 ودعم اللغات

إرجاع الأخطاء وفق الهيكل المعياري RFC 7807 مع دعم ترجمة الرسائل بناءً على ترويسة `Accept-Language`.

---

## ⚡ أوامر سريعة
*   `uvicorn main:app --reload` / `npm run start:dev` — تشغيل الخادم.
*   `dotnet test --collect:"XPlat Code Coverage"` / `go test -v -race ./...` — تنفيذ الاختبارات.

---

## ✅ قائمة التحقق ومعيار الاكتمال (DoD)

*   [ ] فصل الخدمات وقواعد البيانات مطبق وفق نمط Database per Service.
*   [ ] نسبة تغطية الاختبارات تتجاوز 80% وتقييم SonarQube A+ محقق.
*   [ ] ترويسات الأمان HTTP وتحديد معدل الطلبات مفعلة.
*   [ ] معيار RFC 7807 مطبق مع دعم ترويسة Accept-Language.
*   [ ] التخزين المؤقت Redis مطبق مع استراتيجيات منع الانهيار.

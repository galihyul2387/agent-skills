# دليل المرحلة: الاختبارات النهائية، SIT، UAT، وضمان الجودة

تركز هذه المرحلة على التحقق من الوظائف الشاملة للنظام، وتنفيذ اختبارات تكامل النظام (SIT)، واختبارات قبول المستخدم (UAT)، واختبارات الأداء والأمان.

## 1. دورة حياة اختبارات SIT و UAT

*   **اختبار تكامل النظام (SIT):** اختبار تقني شامل يغطي الواجهات الأمامية وبوابات API وقواعد البيانات.
*   **اختبار قبول المستخدم (UAT):** تحقق نهائي من سيناريوهات الأعمال يجريه ملاك المنتج.

---

## 2. وثائق الاختبار الرسمية

*   **خطة الاختبار (Test Plan):** استراتيجية تحدد النطاق والجداول والبيئات.
*   **مصفوفة حالات الاختبار:** جداول تفصيلية للخطوات والنتائج المتوقعة.
*   **سجل الأخطاء (Bug Report):** توثيق التذاكر ومستويات الخطورة.
*   **اعتماد UAT (Sign-Off):** الموافقة الرسمية على الجاهزية للإنتاج.

---

## 3. اختبارات الأداء والأمان

*   **اختبار الحمل (k6):** قياس زمن الاستجابة (P95 < 1s) وسعة المعالجة.
*   **فحص الأمان (OWASP ZAP):** الكشف الآلي عن الثغرات الأمنية.

---

## ⚡ أوامر سريعة
*   `npx playwright test` — تشغيل اختبارات E2E الآلية.
*   `k6 run load-test.js` — تنفيذ اختبارات الأداء k6.

---

## ✅ قائمة التحقق ومعيار الاكتمال (DoD)

*   [ ] إعداد خطة الاختبار ومصفوفة الحالات بالكامل.
*   [ ] تنفيذ سيناريوهات SIT و UAT بدون أخطاء حرجة معلقة.
*   [ ] اجتياز معايير الأداء والفحص الأمني.
*   [ ] اعتماد UAT Sign-Off رسمياً من مالك المنتج.

# دليل المرحلة: تكامل النظام والأمان وتتبع الطلبات

تركز هذه المرحلة على ربط تطبيقات الواجهة الأمامية ببوابات API والخدمات المصغرة، وتفعيل التتبع الموزع للطلبات، وسياسات CORS الصارمة.

## 1. الخطوات الاستراتيجية للتكامل

*   **توحيد المنافذ عبر بوابة API:** توجيه حركة المرور عبر بوابة موحدة (Nginx, Traefik, Kong, YARP).
*   **سياسة CORS صارمة:** السماح بنطاقات الإنتاج المحددة ومنع العلامة النجمية (`*`) مع الاعتمادات.
*   **تتبع الطلبات عبر Correlation ID:** تضمين ترويسة `X-Correlation-ID` وتمريرها لكافة الخدمات المصغرة.
*   **التشفير الداخلي mTLS:** تأمين الاتصالات الداخلية بين الخدمات المصغرة بتشفير متبادل.

---

## 2. اختبارات عقود API (Contract Testing)

*   **التحقق الاستباقي:** مطابقة استجابات API مع نماذج TypeScript و OpenAPI قبل النشر.
*   **كشف التباين التلقائي:** فحص اتساق مخططات OpenAPI في مسار CI.

---

## ⚡ أوامر سريعة
*   `curl -I https://api.perusahaan.com/health` — فحص الترويسات وحالة الأمان.
*   `docker network inspect app-network` — فحص شبكة الحاويات.

## ✅ قائمة التحقق ومعيار الاكتمال (DoD)

*   [ ] التكامل بين الواجهة الأمامية والبوابة والخدمات الخلفية يعمل بنجاح.
*   [ ] سياسة CORS محددة بدقة لبيئة الإنتاج.
*   [ ] ترويسة Correlation ID ممررة عبر كافة السجلات.
*   [ ] اختبارات التكامل الشاملة اجتازت بنجاح.
